# Images and logos: plan

Spec: `docs/superpowers/specs/2026-10-04-images-design.md`. Executed inline, one commit per task, tests first where the
behaviour is code's (parsing, validation, the pipeline); layout is proven on the review page at full size.

1. **`src/engine/images.ts`**: `imageMeta(src)`, `isImageSrc`, `IMAGE_KINDS`, `logoBox` (optical size), `isWordmark`.
   Unit tests.
2. **Schema and types**: the `image` field type (`{ src, alt }`, kind per field), templates `image`, `team`, `logos`;
   `logo` on table cells, table columns and cards; their rules (one logo per row/column or none; leads not mixed; kinds).
   Picking guide entries. Validation tests.
3. **Render and CSS**: the image, team and logos bodies; logo cells, header logos and card logo leads; one-colour masks;
   optical sizing; team grid and initials. Exhaustive maps in the app (`EditBar`, `AddSlide`).
4. **Starter pictures and starters**: an Acme product screenshot (rendered from an HTML mock), team photos, a set of
   fictional customer logos, bundled under `public/starters/img/` with the naming convention; three starters and logos in
   the competitor table. Review page: every new slide in both styles and themes, checked at full size.
5. **Checks and words**: pictures read as words in rule checks, judgment checks and the storyline; the alt-text rule
   check; capabilities for the new templates.
6. **In-app agent**: the image and logos templates are not offered in-app (no way to add a picture there yet); team is.
7. **Pipeline and tool**: `api/_lib/images.ts` (safe fetch, sniff, sharp by kind, background keying, trim, Blob put),
   the `add_image` tool through the registry with an `images` port, rate and daily cap. Tests with fakes for fetch and
   Blob; one real run against the dev Blob store.
8. **MCP text**: instructions and guide name add_image and when each kind goes where; template cards carry the image
   field. Live check with the smartchart MCP server: add a logo from a URL, build a logos slide.
9. **Finish**: FUTURE.md (#6 built; the not-in-this-version items), browser tests, build, lint, full test run.
